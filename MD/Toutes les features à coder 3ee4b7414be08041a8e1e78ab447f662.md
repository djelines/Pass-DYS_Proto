# Toutes les features à coder

## 0 · Socle

- [ ]  Inscription : compte, e-mail, mot de passe
- [ ]  Connexion + mot de passe oublié
- [ ]  Questionnaire d'entrée 1/3 : étape de vie (collège, lycée, études sup., travail, parent)
- [ ]  Questionnaire d'entrée 2/3 : difficultés (lire, écrire, compter, parler, m'organiser)
- [ ]  Questionnaire d'entrée 3/3 : confort de lecture
- [ ]  Profil : identité, étape de vie, casquette de Lio
- [ ]  Confort de lecture appliqué partout : police dys, taille, espacement, contraste, fond, voix et vitesse
- [ ]  Rôle parent : compte lié, ce qu'il voit, ce qu'il peut cocher
- [ ]  Partage et révocation d'accès
- [ ]  Notifications et rappels (dans l'app + mail)

## 1 · Carte de besoins

- [ ]  Besoins proposés selon l'étape de vie
- [ ]  Activer / désactiver chaque besoin
- [ ]  Écrire un besoin personnalisé
- [ ]  Aperçu de la carte (sans diagnostic affiché)
- [ ]  Partage par QR code
- [ ]  Partage par lien privé à durée limitée
- [ ]  Export PDF imprimable

## 2 · Carte des ressources dys

- [ ]  Carte avec géolocalisation et rayon
- [ ]  Filtres par catégorie : santé, bibliothèques adaptées, associations, ULIS, services handicap, centres de bilan adultes
- [ ]  Fiche d'un lieu : nom, adresse, distance, itinéraire
- [ ]  Source affichée pour chaque lieu (data.gouv, Bibliothèques Sonores, FFDys, communauté)
- [ ]  Import et curation des jeux de données ouverts
- [ ]  Proposer un lieu (contribution)
- [ ]  Modération des contributions

## 3 · Préparateur d'entretien et annuaire

- [ ]  Annuaire de spécialistes depuis l'Annuaire Santé (CNAM)
- [ ]  Filtres par spécialité et par distance
- [ ]  Fiche praticien + lien sortant vers sa page de prise de rendez-vous
- [ ]  Scénarios d'entraînement : service handicap, bilan orthophonique, entretien d'embauche, RQTH
- [ ]  Jeu de rôle à l'oral avec Lio (questions probables)
- [ ]  Retour après chaque réponse : ce qui va, ce qu'on peut dire autrement
- [ ]  Préparer un rendez-vous précis (depuis une fiche praticien)

## 4 · Assistant démarches — le cœur

- [ ]  Catalogue des démarches : PAP, PPS, MDPH, aménagement d'examens, RQTH, aménagement de poste
- [ ]  Démarches proposées selon l'étape de vie
- [ ]  Découpage d'une démarche en étapes, avec documents à fournir
- [ ]  Échéances et rappels paramétrables
- [ ]  Progression d'une démarche (étape en cours, suivante)
- [ ]  Liste de tâches partagée avec le parent
- [ ]  Vue kanban : à faire, en cours, en attente, fait
- [ ]  Attribution d'une tâche (moi / le parent)
- [ ]  Sources officielles citées à chaque étape
- [ ]  Rédacteur de mails : je dicte en mes mots, Lio rédige
- [ ]  Choix du destinataire et du ton (professeur, employeur, administration)
- [ ]  Copier / envoyer / écouter le mail

## 5 · Coffre documentaire

- [ ]  Ajouter un document (fichier ou photo)
- [ ]  Catégories : bilans, MDPH, PAP/PPS, fac, RQTH
- [ ]  Recherche et filtres
- [ ]  Document rattaché à une démarche
- [ ]  Partage d'un document avec le parent, et retrait du partage
- [ ]  Téléchargement et suppression
- [ ]  Chiffrement au repos + données fictives en démo
- [ ]  Mention « HDS non implémenté en MVP »

## 6 · Lio, le compagnon

- [ ]  Avatar unique + voix, casquette selon le mode
- [ ]  Brique commune : reconnaissance vocale → LLM → synthèse vocale
- [ ]  Prompt système par mode, selon le profil
- [ ]  Mode dyslexie : scanner un document, lire à voix haute, expliquer un mot, résumer
- [ ]  Mode dyscalculie : décomposer un calcul étape par étape, répéter plus lentement
- [ ]  Mode dysphasie : je dis mon idée, Lio la reformule à l'oral
- [ ]  Mode dyspraxie : découper une tâche du quotidien en étapes, répéter une étape
- [ ]  Mode dysgraphie : dictée corrigée (syntaxe et structure)
- [ ]  Mode entraînement : jeu de rôle (voir feature 3)
- [ ]  Historique des échanges
- [ ]  Garde-fous : clé d'API côté serveur, aucune donnée de santé envoyée au modèle

## 7 · Transverse

- [ ]  Accessibilité RGAA : contrastes, navigation au clavier, lecteur d'écran
- [ ]  Sécurité : authentification, validation des entrées, droits d'accès, requêtes préparées
- [ ]  RGPD : consentement, export et suppression de mes données
- [ ]  Gamification légère : XP, niveaux, série de jours, badges
- [ ]  Tableau de bord d'accueil : quête du jour, rendez-vous, tâches, lieux proches
- [ ]  Recherche globale
- [ ]  Responsive mobile
